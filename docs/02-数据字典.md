## 三、分表字段明细

### 主数据
- **lab_department**：`id`(PK)、`dept_name`(部门名,唯一)、`sort_num`、`enabled`、`created_time`、`updated_time`
- **lab_experiment_item**：`id`(PK)、`item_name`(实验项目名,唯一)、`sort_num`、`enabled`、时间戳
- **lab_dqa_project**：`id`(PK)、`project_name`、`standard`(标准)、`sort_num`、`enabled`、时间戳
- **lab_experiment_task_detail**：`id`、`registration_id`、`machine_type`(机种,唯一)、`primary_assignee`(担当)、`secondary_assignee`(第二代理人)、`created_time`

### 设备域
- **lab_machine**（父·机器类型）：`id`(PK)、`instrument_name`(仪器名称)、`quantity`(数量)、`device_capability`(设备能力)
- **lab_machine_unit**（子·机台）：`id`(PK)、`parent_machine_id`(FK→lab_machine)、`station_code`(机台编号,唯一)、`enabled`、`sort_num`、`unit_length/unit_width/unit_height`(腔体长宽高 m)、`volume`、`volume_unit`(m3/cm3/L)
- **lab_machine_unit_experiment_item**：`machine_unit_id`+`experiment_item_id`(联合 PK，机台可执行项目)
- **lab_machine_load_management**（机台负荷）：`id`(PK)、`machine_id`(关联机台ID→lab_machine_unit)、`machine_model`(机种)、`machine_name`(机台名称)、`is_full`(0未满1已满)、`full_override`(满载覆盖 0自动1强制满2强制未满)、`stack_layer_count`(叠层层数)、`used_cm2_at_full`(手动满时占用cm²)、`endTime`(结束时间)、`confirm_count`(确认枚数)、`completed_count`(完成枚数)、`dept_number`(部番)

### 送检与计划域
- **lab_inspection_registration**（送检登记·申请入口）：见口径表 + `designated_qe`(指定品质工程师)、`experiment_type`(实验类型)、`expected_completion_time`(期望完成)、`receive_opinion`(接收意见)、`application_company`(申请公司)、`inspection_date`(送检日期)、`experiment_progress`(实验进度)、`experiment_responsible_person`(实验责任人)、`inspection_quantity`(送检数量)、`product_length/width/height`(单枚产品尺寸 cm)、`verification_purpose`(验证目的)、`top_flag`(置顶)、`copy_as_new`(复制新建)、`created_by/updated_by`、`sort_num`
- **lab_experiment_plan**（实验计划）：`id`、`registration_id`(FK送检单)、`oa_number`、`task_detail_id`(分工ID)、`completion_status`(完成状态,默认'待测量')、`machine_id`(机台ID)、`experiment_item_id`、`dqa_project_id`、`test_scope_id`、`fee_id`、`fee_quantity`(计费数量)、`experiment_condition_method`(实验条件及方法)、`other_condition_group_id`、`condition_mode`(FLAT/CHAIN)、`current_stage_id`(当前阶段)、`chain_status`(NOT_STARTED等)、`next_transition_at`、`runtime_version`(乐观锁)、`experiment_quantity_pcs`(数量pcs)、`experiment_time`、`experiment_result`(实验结果)、`ng_source_plan_id`、`sample_change_content`、`judgment_standard`(判定标准)、`condition_photo_urls`、`experiment_cost`(实验费用)、`routine_test`(例行试验)、`is_supplier`(是否供应商)、时间戳
- **lab_experiment_plan_stage**（链式阶段）：`id`、`plan_id`(FK)、`stage_order`(阶段序号)、`stage_name`、`duration_seconds`(持续秒数)、`progression_mode`(AUTO/MANUAL)、`runtime_status`(PENDING/RUNNING/WAITING_MANUAL/COMPLETED)、`started_at/due_at/completed_at`
- **lab_experiment_plan_dept**：`plan_id`+`registration_id`(唯一)、`dept_number`(部番)
- **lab_experiment_plan_other_condition / stage_condition**：条件名/值/时长/并行组/排序
- **lab_inspection_machine**（送检机台绑定）：`registration_id`、`plan_id`、`machine_load_id`(FK负荷)、`machine_model`、`dept_number`、`completed_count`、`start_time/end_time`、`is_picked_up`(是否取出)、`pickup_time/pickup_by`、`allow_stacking`(可叠放)
- **lab_inspection_handover_log**（交接完工）：`registration_id`、`receiver`(接收人)、`receive_date`(接入日期)

### 结果与评价域
- **lab_reliability_experiment_reg**（可靠性/NG 登记）：`id`、`registration_id`、`plan_id`、`ng_count`(NG数)、`sample_count`(样品数)、`experiment_result`(实验结果)、`ng_inspector`(NG检验人员)、`ng_machine_id`(指定机台)、`ng_operate_start/end`(NG操作起止)、`duration`(耗时)、`month`(月份)、`date`(日期)、`machine_model`(机种)、`business_dept`(事业部)、`entrusting_dept`(委托部门)、`entruster`(委托人)、`experiment_category`(实验分类)、`experiment_item_id`、`experiment_condition`、`experiment_assignee`(实验担当)、`machine_number`(机台编号)、`piece_count`(件数)、`sample_change_content`、`defect_rate`(不良率%)
- **lab_dqa_optical_evaluation**（DQA 光学评价）：`id`、`registration_id`、`plan_id`、`month`、`dept_number`、`machine_type`、`evaluation_purpose`(评价目的)、`entrusting_dept`(委托部门)、`evaluation_stage`(评价阶段)、`experiment_item_id`、`dqa_project_id`、`evaluation_result`(评价结果:合格/不合格)、`remark`(原因)、时间戳

### 报价域
- **lab_experiment_price_quote**（报价主表）：`id`、`quote_mode`(experiment_item|machine)、`oa_number`、`machine_type`、`dept_number`、`business_unit`(事业部)、`applicant`(送检人)、`department_id`(FK部门)、`department_name`(部门名称)、`contact_phone`、`inspection_time`(送检时间)、`is_supplier`、`total_experiment_price`(合计价格)
- **lab_experiment_price_quote_line**（报价明细）：`id`、`quote_id`(FK)、`sort_num`、`machine_unit_id`(机台ID)、`station_code`(机台编号)、`instrument_name`(仪器名称)、`experiment_item_id/experiment_item_name`、`test_scope_id`、`experiment_condition`(测试范围)、`fee_id`、`specific_condition`(费用项说明)、`hourly_rate`(单价)、`fee_unit`(费用单位)、`fee_quantity`(计费数量)、`fee_quantity_label`、`experiment_price`(实验价格)、`cost_formula`(计算说明)

## 四、字段口径映射（需求 → 数据源）

| 需求模块 | 维度/指标 | 数据源表 | 关键字段 |
|---|---|---|---|
| 二·数字孪生 | 设备模型 | lab_machine, lab_machine_unit | instrument_name, station_code, unit_length/width/height |
| 二·设备详情 | 负荷/占用 | lab_machine_load_management | machine_id, machine_name, is_full, completed_count, endTime, dept_number |
| 三·利用率 | 机台占用/趋势 | lab_machine_load_management | is_full, endTime, machine_id |
| 四·事业部占用 | business_unit | lab_machine_load_management(+join), lab_inspection_registration | dept_number, business_unit |
| 五·机种占比 | machine_type | lab_inspection_registration / lab_machine_load_management | machine_type |
| 六·申请分析 | 部门/类型/类别/供应商 | lab_inspection_registration | application_department, request_type, category, is_supplier, inspection_date |
| 七·完成率 | completion_status | lab_experiment_plan | completion_status |
| 八·异常分析 | NG | lab_reliability_experiment_reg | ng_count, sample_count, experiment_item_id, machine_model, ng_machine_id, ng_inspector, remark |
| 九·结果分析 | OK/NG | lab_reliability_experiment_reg, lab_dqa_optical_evaluation | experiment_result, evaluation_result |
| 十·DQA 专项 | 项目/目的/阶段/结果 | lab_dqa_optical_evaluation, lab_dqa_project | dqa_project_id, evaluation_purpose, evaluation_stage, evaluation_result, month |
| 十一·报价 | 部门/事业部/项目/设备/成本 | lab_experiment_price_quote(+line) | department_name, business_unit, experiment_item_name, instrument_name, experiment_price, inspection_time |
