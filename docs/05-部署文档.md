# 部署文档 —— 智能实验室数字孪生运营驾驶舱

## 1. 环境要求

| 组件 | 版本 | 说明 |
|---|---|---|
| JDK | 17+ | 后端 Spring Boot 3.2.5 构建/运行 |
| Maven | 3.9+ | 后端构建 |
| Node.js | 18+/20+ | 前端构建 |
| MySQL | 8.0+ | 业务 OLTP（`ruoyi7` 库，23 张 `lab_*` 表） |
| Redis | 6+ | 热点缓存（可选但推荐） |
| ClickHouse | 22+ | 分析 OLAP（可选，未配置自动回退 MySQL） |

## 2. 目录结构

```
lab-digital-twin/
├── docs/           # 01 架构设计 / 02 数据字典 / 03 统计口径 / 04 ClickHouse 同步 / 05 部署文档
├── sql/
│   ├── mysql/stats-analysis.sql      # 统计 SQL（需求三~十一）
│   └── clickhouse/clickhouse_ddl.sql # ClickHouse 事实/维度表 DDL
├── backend/        # Spring Boot 3 后端
└── frontend/       # Vue3 + Vite 前端
```

## 3. 数据库初始化

1. 在 MySQL 建库：`CREATE DATABASE ruoyi7 DEFAULT CHARACTER SET utf8mb4;`
2. 导入 23 张 `lab_*` 表结构（Navicat 导出的 DDL）。
3. 统计 SQL 无需建表，直接供后端 MyBatis `StatsMapper` 执行；`sql/mysql/stats-analysis.sql` 为口径参考与离线核对用。

## 4. 后端构建与运行

```bash
cd backend
# 修改 src/main/resources/application.yml：数据库账号密码、Redis 地址
mvn clean package -DskipTests
java -jar target/lab-twin-1.0.0.jar
```

- 端口默认 `8080`。
- 无登录模块，启动后前端直接访问驾驶舱接口。
- WebSocket 端点 `/ws`（STOMP），广播频道 `/topic/device-status`、`/topic/experiment-status`。

### 关键配置（application.yml → lab 节点）

```yaml
lab:
  clickhouse:
    enabled: false          # 置 true 且配置 url 后启用 ClickHouse
    url: jdbc:clickhouse://localhost:8123/lab_dw
  sync:
    enabled: false          # 置 true 后启用 MySQL→ClickHouse 增量同步
    interval-ms: 60000
  realtime:
    enabled: false          # 置 true 后启用设备状态定时推送（无 CDC 时的实时方案）
    interval-ms: 5000
```

## 5. 前端构建与运行

```bash
cd frontend
npm install
npm run dev      # 开发：http://localhost:5173，已配置 /api、/ws 代理到 8220
npm run build    # 生产构建：产出 dist/（已内含 three / G6，浏览器不再访问 npm）
```

Windows 一键打静态包并拷进后端 jar：

```powershell
cd frontend
powershell -ExecutionPolicy Bypass -File scripts\build-static.ps1
```

### 静态部署（推荐）

`npm run build` 已经把 Vue、ECharts、Three.js、AntV G6 **全部打进 `dist/assets/*.js`**，服务器上不需要再执行 `npm install` 给浏览器用。

1. 把 `frontend/dist/` **整个目录**拷到 Nginx html 根（参考 `frontend/nginx.conf.example`）。
2. Nginx 把 `/api`、`/ws` 反代到后端 `8220`。
3. 用**本机浏览器**打开页面，不要用远程桌面在服务器里开 IE/无 GPU 的浏览器看 3D。

也可不装 Nginx：执行 `build-static.ps1` 后 `mvn package`，静态页打进 jar，访问 `http://服务器:8220/`。

### 关系分析 / 数字孪生在服务器上看不到？

**一般不是 CPU/内存不够。** 3D 是浏览器 WebGL 渲染：

| 常见原因 | 处理 |
|---|---|
| 远程桌面进服务器看，虚拟机没 GPU | 用办公电脑浏览器访问页面 |
| 只 `npm install` 没把 `dist` 拷到 Nginx | 必须拷贝 `dist` 全部文件，尤其是 `assets/` |
| `npm run build` 被类型检查拦住，dist 是旧的 | 现已改为直接 `vite build` |
| 页面挂在子路径，JS 404 | 已设 `base: './'` 相对路径 |

## 6. ClickHouse 落地步骤（可选加速层）

1. 执行 `sql/clickhouse/clickhouse_ddl.sql` 建 `lab_dw` 库与事实/维度/物化视图表。
2. `application.yml` 设 `lab.clickhouse.enabled=true`、`lab.sync.enabled=true`，配置 url/账号。
3. 首次执行全量同步（管理接口或启动开关），此后按水位线增量同步（详见 docs/04）。
4. 长周期趋势查询接口按数据源路由到 ClickHouse，未配置时自动回退 MySQL，功能不中断。

## 7. 端到端验证清单

1. 后端启动无异常（连接 MySQL/Redis 成功）。
2. `GET /api/dashboard/overview` 返回六大指标。
3. `GET /api/dashboard/devices` 返回机台+负荷列表（数字孪生数据源）。
4. `GET /api/analysis/**`、`/api/ai/**`、`/api/relation/graph` 返回聚合数据。
5. 前端 `/dashboard`（默认首页）六大指标卡显示；`/twin` 三维设备模型渲染、点击弹层、WebSocket 变色；`/analysis` 九大看板；`/ai` 六模块；`/relation` 关系网络。
