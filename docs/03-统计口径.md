# 统计口径定义（单一事实来源）

> 本文件定义全部指标的数学口径与枚举约定，后端统计 SQL、ClickHouse 聚合、前端展示共用。凡业务枚举值未在 DDL 明确列出的，给出**默认约定**并标注 `[约定]`，可在实施阶段据真实数据微调。

## 1. 全局约定

- 主键均为 `varchar(32)` UUID；时间字段为 `datetime`/`date`。
- 所有金额字段单位：**元**，`decimal(14,2)`/`decimal(12,2)`。
- 供应商标识 `is_supplier`：`0=否，1=是`。
- 时间维度切片统一用日期边界：日=`DATE(时间字段)`、周=ISO 周（`YEARWEEK(...,3)`）、月=`DATE_FORMAT('%Y-%m')`、季度=`QUARTER()`+年。

## 2. 首页六大指标

| 指标 | 口径 | 数据源 |
|---|---|---|
| 今日实验数量 | 今日 `inspection_date = CURDATE()` 的送检登记数 | lab_inspection_registration |
| 进行中实验 | `completion_status` 属于「进行中」集合的计划数 | lab_experiment_plan |
| 完成实验 | `completion_status = '已完成'` 的计划数 | lab_experiment_plan |
| 异常实验 | 今日存在 NG 记录（ng_count>0 或 result 为 NG）的实验数 | lab_reliability_experiment_reg |
| 设备利用率 | 见 §3 | lab_machine_load_management |
| 实验完成率 | 见 §5 | lab_experiment_plan |

## 3. 设备利用率

- **机台占用率**（实时）：`占用中的机台数 / 启用机台总数`
  - 占用中 = `lab_machine_load_management` 中存在「未释放负荷」的机台（`endTime IS NULL` 或 `endTime > NOW()`，且 `is_full` 不排斥计数）。
  - 启用机台总数 = `lab_machine_unit.enabled = 1` 的记录数。
- **利用率趋势**（日/周/月）：`该时段内被占用的机台·天（或小时）数 / (启用机台数 × 时段天数)`，按 `lab_inspection_machine.start_time/end_time` 的占用区间计算；缺历史区间时用 `lab_machine_load_management` 快照估算 `[约定]`。
- **设备空闲率** = `1 - 机台占用率`。
- **负载排行**：按「当前占用负荷」降序，负荷 = `is_full`（满=1）优先 + `completed_count`（完成枚数）作强度，负荷强度记为 `is_full*100 + completed_count` `[约定]`。

## 4. NG / 异常

- **NG 数量**：`SUM(ng_count)`（ng_count 为 NULL 视为 0）。
- **NG 比例**：`SUM(ng_count) / SUM(sample_count)`，sample_count>0 才参与分母。
- **异常趋势**：按日聚合 NG 记录数或 NG 件数。
- **NG 原因**：`lab_reliability_experiment_reg.remark`（或 `experiment_result`）作为原因维度 `[约定]`。

## 5. 完成率

- 公式：`完成数量 / 总计划数量`。
- 完成 = `lab_experiment_plan.completion_status = '已完成'`；总计划 = 该范围内全部 `lab_experiment_plan` 记录。
- **每日完成率趋势**：按 `updated_time` 日期分组，当日完成数 / 当日计划总数。
- 状态枚举 `[约定]`：`待测量 / 进行中 / 已完成 / 已取消`，其中「进行中」集合 = 非 `待测量` 且非 `已完成` 且非 `已取消`。

## 6. 合格率（结果分析）

- 实验申请单：`OK 数 / (OK 数 + NG 数)`，OK/NG 由 `lab_reliability_experiment_reg.experiment_result` 判定（含 "OK"/"NG"/"合格"/"不合格"，大小写不敏感 `[约定]`）。
- DQA 申请单：`evaluation_result = '合格' 数 / (合格 + 不合格 数)`。
- **系统不判定结果，只统计已有结果**；空结果记录不纳入分子分母。

## 7. 报价金额

- 部门/事业部报价金额 = `SUM(total_experiment_price)`，按 `department_name`/`business_unit` 分组。
- 实验项目收费排行 = 按 `quote_line.experiment_item_name` 分组 `SUM(experiment_price)`。
- 设备实验收入排行 = 按 `quote_line.instrument_name` 分组 `SUM(experiment_price)`。
- 成本趋势 = 按 `inspection_time` 月维度 `SUM(total_experiment_price)`（以报价金额近似成本 `[约定]`，因 DDL 无独立成本字段）。

## 8. 时间维度模板

```sql
-- 日
DATE_FORMAT(d, '%Y-%m-%d')
-- 周
YEARWEEK(d, 3)
-- 月
DATE_FORMAT(d, '%Y-%m')
-- 季度
CONCAT(YEAR(d), 'Q', QUARTER(d))
```

## 9. 枚举约定汇总（实施时可调）

| 字段 | 约定枚举 |

| lab_experiment_plan.completion_status | 待测量 / 进行中 / 已完成 / 已取消 |
| lab_reliability_experiment_reg.experiment_result | OK / NG / 合格 / 不合格 |
| lab_dqa_optical_evaluation.evaluation_result | 合格 / 不合格 |
| lab_experiment_plan_stage.runtime_status | PENDING / RUNNING / WAITING_MANUAL / COMPLETED |
| lab_experiment_price_quote.quote_mode | experiment_item / machine |
